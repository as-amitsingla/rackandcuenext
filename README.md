# Rack & Cue — Table Manager

Production-ready Next.js dashboard for managing snooker and pool table sessions.

## Features

- Live table status and timers
- Explicit amount calculation
- Session start/stop workflow
- Session history with edit/delete
- Configurable hourly rates
- Responsive admin dashboard
- Local browser persistence via localStorage

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
